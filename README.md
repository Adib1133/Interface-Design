A simple **Event Management Web Application** built as an assignment project.  
This project demonstrates **front-end web development** skills using Vue.js and Bootstrap.  

---

## ✨ Features  
- Responsive landing page with **modern UI**  
- Browse and filter **upcoming events** by ID, name, duration, or category  
- **Event registration form** with:  
  - Username and password validation  
  - Password confirmation check  
  - Dynamic event listing based on category  
- **Registration modal** displaying user details after submission  

---

## 🛠️ Tech Stack  
- **HTML5, CSS3, SCSS** – Structure and styling  
- **Bootstrap 5** – Responsive components  
- **FontAwesome** – Icons  
- **Vue.js (v3)** – Reactive forms and event filtering
